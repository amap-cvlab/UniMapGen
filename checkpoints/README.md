# UniMapGen v6 checkpoint

Model weights are intentionally excluded from Git.

The code was validated with the designated final v6 checkpoint from experiment
`0502_v6_opensatmap20_896` at training step `26000`. Publish the authorized
checkpoint through a large-file model host and place the extracted Hugging
Face-format files in
`checkpoints/unimapgen-v6/`.

Before a public release, add the following information here:

- public download URL;
- SHA256 for every `*.safetensors` shard;
- base-model name and license;
- training-data summary and permitted uses;
- known limitations and responsible-use notes.
